# Group 7 Design Project - Trinity Transit

## Overview
How to set up the database for the Trinity Transit in a Docker container.

## Running the MySQL Script

### Prerequisites
- Ensure the Docker daemon is installed and running on your machine.

### Steps to Run the Script

1. Open your terminal or command prompt to the root directory ../../sweng-g7

2. Run the command 'docker-compose up' to start the MySQL server
